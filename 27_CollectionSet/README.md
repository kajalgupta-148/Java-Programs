# Collection Set in Java

This folder contains programs for the `Set` interface and its common implementations in Java.

## Folders Covered

### 1. HashSet
Stores unique elements and does not guarantee iteration order.

### 2. LinkedHashSet
Stores unique elements and maintains insertion order.

### 3. TreeSet
Stores unique elements in sorted order.

## Topics Covered

- `add()`, `remove()`, `contains()`, `size()`, `isEmpty()`, and `clear()`
- Duplicate prevention and iteration
- Taking user input
- Union, intersection, and difference
- Removing duplicates while preserving insertion order
- Ascending and descending order
- `first()`, `last()`, `lower()`, `higher()`, `floor()`, and `ceiling()`
- `headSet()`, `tailSet()`, and `subSet()`
