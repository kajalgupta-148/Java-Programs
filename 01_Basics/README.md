# Basics of Java

This folder contains basic Java programs to understand the fundamentals of Java programming.

## Programs Covered

### 1. Data Type Demo
Demonstrates different data types available in Java.

Example:
- DataTypeDemo.java

### 2. Hello World
Demonstrates the basic structure of a Java program and prints a simple message.

Example:
- Hello.java

### 3. Print Name
Demonstrates how to print a name using Java.

Example:
- PrintName.java

### 4. Variable Demo
Demonstrates the declaration and use of variables in Java.

Example:
- VariableDemo.java

## Topics Covered

- Java program structure
- Variables
- Data types
- Printing output
- `System.out.println()`
- Basic syntax
- `main()` method
- Java fundamentals
