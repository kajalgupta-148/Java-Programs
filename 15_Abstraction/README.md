# Abstraction in Java

Abstraction in Java is used to hide implementation details and show only the essential features of an object.

## Ways to Achieve Abstraction

### 1. Abstract Class

An abstract class is declared using the `abstract` keyword. It can contain abstract methods as well as normal methods.

Example:
- Car.java
- Circle.java
- Developer.java
- Dog.java
- SBI.java

### 2. Interface

An interface is used to achieve abstraction and define a contract that implementing classes must follow.

Example:
- C.java
- Car.java
- Demo.java
- Dog.java
- Eagle.java
