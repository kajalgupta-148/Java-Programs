# Polymorphism in Java

Polymorphism in Java means "many forms". It allows the same method name to perform different tasks depending on how it is used.

## Types of Polymorphism

### 1. Compile-Time Polymorphism

Compile-time polymorphism is achieved through **method overloading**. The method to be executed is decided at compile time.

Example:
- MethodOverloading.java
- MethodOverloading1.java
- MethodOverloading2.java
- MethodOverloading3.java

### 2. Run-Time Polymorphism

Run-time polymorphism is achieved through **method overriding**. The method to be executed is decided at run time.

Example:
- MethodOverriding.java
- MethodOverriding1.java
- MethodOverriding2.java
- MethodOverriding3.java
