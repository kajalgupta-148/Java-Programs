# File Handling in Java

File handling in Java is used to read data from files, write data into files, and manage file operations using streams.

## Programs Covered

### 1. File Output Stream
Writes data into a file using `FileOutputStream`.

Example:
- FileOutputStreamDemo.java

### 2. File Input Stream
Reads data from a file using `FileInputStream`.

Example:
- FileInputStreamDemo.java

### 3. Copy File
Copies data from one file to another using byte streams.

Example:
- CopyFile.java

### 4. Append File
Adds new data to an existing file using append mode.

Example:
- AppendFile.java

### 5. File Reader
Reads character data from a file using `FileReader`.

Example:
- FileReaderDemo.java

### 6. File Writer
Writes character data into a file using `FileWriter`.

Example:
- FileWriterDemo.java

### 7. File Writer Append
Appends additional text to an existing file.

Example:
- FileWriterAppend.java

### 8. Read Characters
Reads characters from a file using a character array.

Example:
- ReadCharacters.java

### 9. Read File
Reads file contents using `read()`.

Example:
- ReadFile.java

### 10. Byte Stream
Writes bytes into a file using `FileOutputStream`.

Example:
- ByteStreamDemo.java

### 11. Character Stream
Writes character data into a file using `FileWriter`.

Example:
- CharacterStreamDemo.java

### 12. File Exception Handling
Handles file-related exceptions using `try-catch-finally`.

Example:
- FileExceptionHandling.java
