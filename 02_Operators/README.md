# Operators in Java

Operators in Java are symbols used to perform operations on variables and values.

## Types of Operators

### 1. Arithmetic Operators
Used to perform basic mathematical operations such as addition, subtraction, multiplication, division, and modulus.

Example:
- ArithOp.java

### 2. Assignment Operators
Used to assign and update values of variables.

Example:
- AssignOp.java

### 3. Conditional Operator
The conditional operator is used to make simple decisions using the `?:` operator.

Example:
- CondiOp.java

### 4. Increment and Decrement Operators
Used to increase or decrease the value of a variable by one.

Example:
- IncreDecre.java

### 5. Logical Operators
Used to perform logical operations such as AND, OR, and NOT.

Example:
- LogicOp.java

### 6. Relational Operators
Used to compare two values.

Example:
- RelationalOp.java

- Arithmetic operators

- `&&`, `||`, `!`
