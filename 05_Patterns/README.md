# Patterns in Java

Pattern programs in Java are used to practice loops, nested loops, and logical thinking by printing different shapes and designs.

## Programs Covered

### 1. Full Pyramid
Prints a full pyramid pattern using stars.

Example:
- FullPyrmid.java

### 2. Hollow Rectangle
Prints a rectangle with stars only on its boundary.

Example:
- HollowRect.java

### 3. Hollow Square
Prints a square with stars only on its boundary.

Example:
- HollowSquare.java

### 4. Inverted Pyramid
Prints an inverted pyramid pattern.

Example:
- InvertedPyramid.java

### 5. Inverted Right Triangle
Prints an inverted right triangle pattern.

Example:
- InvertedRigTriangle.java

### 6. Left Triangle
Prints a left-aligned triangle pattern.

Example:
- LeftTriangle.java

### 7. Right Triangle
Prints a right-aligned triangle pattern.

Example:
- RightTriangle.java

### 8. Square Pattern
Prints a square pattern using stars.

Example:
- SquarePattern.java

## Topics Covered

- Pattern printing
- Nested loops
- `for` loop
- Stars and spaces
- Pyramid patterns
- Triangle patterns
- Square patterns
- Hollow patterns
- Inverted patterns
- Logical thinking
