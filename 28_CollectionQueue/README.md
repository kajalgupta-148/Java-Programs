# Queue Interface in Java

The `Queue` interface in Java is used to store and process elements in FIFO order (First In, First Out).

## Programs Covered

### 1. Queue Basics
Demonstrates adding and removing elements using a Queue.
- QueueBasics.java

### 2. Queue Methods
Demonstrates `add()`, `offer()`, `peek()`, `element()`, `poll()`, and `remove()`.
- QueueMethods.java

### 3. Queue Traversal
Demonstrates traversing a Queue using a loop and iterator.
- QueueTraversal.java

### 4. Queue User Input
Demonstrates adding user-input elements to a Queue.
- QueueUserInput.java

### 5. Priority Queue
Demonstrates elements arranged according to priority (natural ordering).
- PriorityQueueBasics.java

### 6. Priority Queue Methods
Demonstrates common methods of PriorityQueue.
- PriorityQueueMethods.java

### 7. Priority Queue Custom Order
Demonstrates a PriorityQueue using a custom comparator.
- PriorityQueueCustomOrder.java

## Topics Covered
- `Queue` interface and FIFO
- `PriorityQueue`
- `add()`, `offer()`, `peek()`, `element()`
- `poll()`, `remove()`, `contains()`
- `size()` and `clear()`
- Iterator and traversal
- Natural ordering and custom Comparator
