# Constructor in Java

A constructor in Java is a special method used to initialize objects of a class.

## Types and Concepts of Constructor

### 1. Default Constructor
A constructor that is provided by the compiler when no constructor is defined in the class.

Example:
- DefaultConstructor

### 2. Parameterized Constructor
A constructor that accepts parameters to initialize an object with specific values.

Example:
- ParametrizedConstructor

### 3. Constructor Overloading
Defining multiple constructors in the same class with different parameters.

Example:
- ConstructorOverloading
