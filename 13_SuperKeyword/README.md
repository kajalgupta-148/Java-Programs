# Super Keyword in Java

The `super` keyword in Java is used to refer to the immediate parent class.

## Uses of Super Keyword

### 1. Calling Parent Class Constructor
The `super()` keyword is used to call the constructor of the parent class.

Example:
- SuperConstructor.java
- SuperConstructor1.java
- SuperConstructor2.java
- SuperConstructor3.java

### 2. Calling Parent Class Method
The `super.methodName()` is used to call a method of the parent class.

Example:
- SuperMethod.java
- SuperMethod1.java
- SuperMethod2.java
- SuperMethod3.java

### 3. Accessing Parent Class Variable
The `super.variableName` is used to access a variable of the parent class.

Example:
- SuperVariable.java
- SuperVariable1.java
- SuperVariable2.java
- SuperVariable3.java

- Inheritance
