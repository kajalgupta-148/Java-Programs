# Packages in Java

A package in Java is used to group related classes and interfaces together. It helps organize code and provides better access control.

## Programs Covered

### 1. Package Creation
Demonstrates how to create and use a class from a user-defined package.

Example:
- Calculator.java
- Test.java

### 2. Importing Package
Demonstrates importing all classes from a package using the `*` symbol.

Example:
- Message.java
- Demo.java

### 3. Specific Class Import
Demonstrates importing and using a specific class from a package.

Example:
- Area.java
- Main.java

### 4. Static Import
Demonstrates importing static members from another package using the `static` keyword.

Example:
- PI.java
- Calc.java

### 5. Public Access
Demonstrates accessing a public class and method from another package.

Example:
- Student.java
- StudentDemo.java
