# Blocks in Java

Blocks in Java are used to group multiple statements together and control when those statements are executed.

## Types of Blocks

### 1. Instance Initialization Block
An instance initialization block is used to initialize instance variables and is executed when an object is created.

Example:
- InitBlock

### 2. Static Block
A static block is used to initialize static variables and is executed when the class is loaded.

Example:
- StaticBlock

### 3. Static Method
A static method belongs to the class rather than an object and can be called using the class name.

Example:
- StaticMethod

### 4. Static Variable
A static variable is shared among all objects of a class and belongs to the class.

Example:
- StaticVariable
