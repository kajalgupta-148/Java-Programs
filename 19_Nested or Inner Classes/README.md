# Nested or Inner Classes in Java

An inner class in Java is a class defined inside another class. It is treated as a member of the outer class and can access its members.

## Types of Inner Classes

### 1. Non-Static Inner Class
A non-static inner class is associated with an object of the outer class and can access its members.

Example:
- NonStaticInner.java
- NonStaticInner2.java

### 2. Static Inner Class
A static inner class is associated with the outer class rather than its object.

Example:
- StaticInner1.java
- StaticInner2.java

### 3. Local Inner Class
A local inner class is declared inside a method or block.

Example:
- LocalInner1.java
- LocalInner2.java

### 4. Anonymous Inner Class
An anonymous inner class is a class without a name, commonly used with interfaces and abstract classes.

Example:
- AnonymousInner1.java
- AnonymousAbstract.java
- AnonymousInner2.java
