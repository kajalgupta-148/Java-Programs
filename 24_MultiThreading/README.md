# Multithreading in Java

Multithreading in Java allows multiple threads to execute concurrently within a program.

## Programs Covered

### 1. Thread Class
Demonstrates creating a thread by extending the `Thread` class.

Example:
- ThreadClassDemo.java

### 2. Runnable Interface
Demonstrates creating a thread by implementing the `Runnable` interface.

Example:
- RunnableDemo.java

### 3. Number Thread
Prints numbers using a separate thread.

Example:
- NumberThread.java

### 4. Thread Sleep
Demonstrates the use of `Thread.sleep()` to pause thread execution.

Example:
- ThreadSleepDemo.java

### 5. Two Threads
Demonstrates running two threads concurrently.

Example:
- TwoThreadsDemo.java

### 6. Multiple Threads
Creates multiple threads using the `Thread` class.

Example:
- MultipleThreads.java

### 7. Multiple Runnable Threads
Creates multiple threads using the `Runnable` interface.

Example:
- MultipleRunnable.java

### 8. Thread Name
Demonstrates setting and retrieving a thread's name.

Example:
- ThreadNameDemo.java

### 9. Current Thread
Demonstrates the `currentThread()` method and thread information.

Example:
- CurrentThreadDemo.java

### 10. Join Method
Demonstrates the use of `join()` to wait for a thread to finish.

Example:
- ThreadJoinDemo.java

### 11. Thread Priority
Demonstrates setting and retrieving thread priorities.

Example:
- ThreadPriorityDemo.java

### 12. Start vs Run
Explains the difference between calling `start()` and `run()`.

Example:
- StartVsRun.java
