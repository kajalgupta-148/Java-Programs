# ArrayList in Java

This folder contains Java programs to practice the `ArrayList` class from the `java.util` package.

## Programs Covered

- ArrayList creation and adding elements
- Common methods: `size()`, `isEmpty()`, `contains()`, `indexOf()`, `get()`, `set()`, `add()`, `remove()`, and `clear()`
- Searching, updating, and removing elements
- Traversing with loops, `Iterator`, and `forEach()`
- Taking user input
- Duplicate elements
- Sorting, reversing, copying, and converting to an array
- Storing custom objects such as student records and products

## Topics Covered

- Generics
- Dynamic resizing
- Index-based access
- Iteration
- `Collections` utility methods
- Classes, objects, getters, and setters
