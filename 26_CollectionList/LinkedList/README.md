# LinkedList in Java

A `LinkedList` stores elements in a sequence and supports adding or removing elements at both ends. In Java, `LinkedList` implements the `List` and `Deque` interfaces.

## Programs Covered

- Creating a LinkedList and adding elements
- Common methods: `size()`, `isEmpty()`, `contains()`, `indexOf()`, `getFirst()`, and `getLast()`
- Adding and removing elements at the beginning and end
- Searching and taking user input
- Traversing with loops and iterators
- Descending iterator
- Duplicate elements
- Sorting and reversing
- Queue, deque, and stack operations
- Storing custom objects such as student records

## Topics Covered

- `LinkedList`
- `addFirst()` and `addLast()`
- `removeFirst()` and `removeLast()`
- `offer()`, `peek()`, and `poll()`
- `push()` and `pop()`
- `Iterator`
- `Collections.sort()` and `Collections.reverse()`
