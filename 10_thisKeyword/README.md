# this Keyword in Java

The `this` keyword in Java is used to refer to the current object of the class.

## Uses of this Keyword

### 1. Referring to the Current Object
The `this` keyword is used to refer to the current object of the class.

Example:
- CurrentObject

### 2. Returning the Current Object
The `this` keyword can be used to return the current object from a method.

Example:
- ReturnStatement

### 3. Resolving Same Variable Name
The `this` keyword is used to differentiate between instance variables and local variables when they have the same name.

Example:
- SameVariableName
