# Inheritance in Java

This folder contains Java programs that demonstrate the concept of Inheritance in Java.

## What is Inheritance?

Inheritance is an Object-Oriented Programming (OOP) concept in which a child class acquires the properties and methods of a parent class.

Inheritance helps in:

- Code reusability
- Reducing code duplication
- Method overriding
- Establishing relationships between classes

## Syntax

```java
class Parent {
    // Parent class
}

class Child extends Parent {
    // Child class
}
