# Inheritance in Java

Inheritance in Java is a mechanism through which a child class acquires the properties and methods of a parent class.

## Types and Concepts of Inheritance

### 1. Single Level Inheritance
One child class inherits from one parent class.

Example:
- SingleLevelInheritance

### 2. Multilevel Inheritance
A class inherits from another class, which itself inherits from another class.

Example:
- MultilevelInheritance

### 3. Hierarchical Inheritance
Multiple child classes inherit from the same parent class.

Example:
- HierarchicalInheritance

### 4. Private Method
Demonstrates the behavior of private methods in inheritance.

Example:
- PrivateMethod

### 5. Final Method
Demonstrates the use of the `final` keyword with methods in inheritance.

Example:
- FinalMethod
