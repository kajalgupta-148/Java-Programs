# Lambda Expression in Java

Lambda expressions were introduced in Java 8. They are used to provide a simple way to implement functional interfaces.

## Programs Covered

### 1. Lambda with No Argument
Demonstrates a lambda expression without any argument.

Example:
- LambdaNoArgument.java

### 2. Lambda with Return Statement
Demonstrates a lambda expression that returns a value.

Example:
- LambdaReturn.java

### 3. Lambda with One Argument
Demonstrates a lambda expression with a single argument.

Example:
- LambdaArgument.java

### 4. Lambda with Multiple Arguments
Demonstrates a lambda expression with multiple arguments.

Example:
- LambdaMultipleArguments.java

### 5. Lambda for Even or Odd
Demonstrates using a lambda expression to check whether a number is even.

Example:
- LambdaEvenOdd.java

### 6. Lambda for Square
Demonstrates using a lambda expression to calculate the square of a number.

Example:
- LambdaSquare.java
