# Garbage Collection in Java

Garbage Collection in Java is the process of automatically removing unused objects from memory.

## Programs Covered

### 1. Null Reference
Demonstrates making an object eligible for garbage collection by setting its reference to `null`.

Example:
- `NullReferenceGC.java`

### 2. Reassigning Reference
Demonstrates how an object becomes eligible for garbage collection when its reference is reassigned.

Example:
- `ReassignReferenceGC.java`

### 3. Anonymous Object
Demonstrates creating an object without storing its reference in a variable.

Example:
- `AnonymousObjectGC.java`

### 4. System.gc()
Demonstrates requesting garbage collection using `System.gc()`.

Example:
- `SystemGCDemo.java`

### 5. finalize() Method
Demonstrates the `finalize()` method associated with garbage collection.

Example:
- `FinalizeDemo.java`

### 6. Multiple Objects
Demonstrates making multiple objects eligible for garbage collection.

Example:
- `MultipleObjectsGC.java`

## Topics Covered

- Garbage Collection
- Object eligibility for garbage collection
- Null reference
- Reassigning object references
- Anonymous objects
- `System.gc()`
- `finalize()` method
- Memory management in Java
