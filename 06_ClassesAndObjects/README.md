# Classes and Objects in Java

Classes and Objects are the basic building blocks of Object-Oriented Programming (OOP) in Java.

## What is a Class?

A class is a blueprint or template used to create objects. It contains variables and methods that define the properties and behavior of an object.

## What is an Object?

An object is an instance of a class. It represents a real-world entity and is used to access the members of a class.
