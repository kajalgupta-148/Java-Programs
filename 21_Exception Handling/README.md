# Exception Handling in Java

Exception handling in Java is used to handle runtime and compile-time errors and prevent abnormal termination of a program.

## Programs Covered

### 1. Try-Catch
Demonstrates basic exception handling using `try` and `catch`.

Example:
- TryCatch.java

### 2. Array Exception
Handles an invalid array index.

Example:
- ArrayException.java

### 3. Null Pointer Exception
Handles a null object reference.

Example:
- NullPointerException.java

### 4. Input Mismatch Exception
Handles invalid input entered by the user.

Example:
- InputMismatchException.java

### 5. Multiple Catch
Demonstrates handling different exceptions using multiple `catch` blocks.

Example:
- MultipleCatch.java

### 6. Instanceof with Exception
Demonstrates checking the type of exception using `instanceof`.

Example:
- InstanceOfException.java

### 7. Throw Keyword
Demonstrates creating and throwing an exception using `throw`.

Example:
- ThrowKeyword.java

### 8. Custom Exception
Demonstrates creating a user-defined exception.

Example:
- CustomException.java

### 9. Custom Exception with Parameter
Demonstrates a custom exception with a parameterized message.

Example:
- CustomException2.java

### 10. Throws Keyword
Demonstrates declaring an exception using `throws`.

Example:
- ThrowsKeyword.java

### 11. Finally Block
Demonstrates the use of the `finally` block.

Example:
- FinallyBlock.java

### 12. Finally Without Exception
Demonstrates that the `finally` block executes when no exception occurs.

Example:
- FinallyWithoutException.java
